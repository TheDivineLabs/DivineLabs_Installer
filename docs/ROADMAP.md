# Roadmap

[Home](../README.md) · [Suggest a workflow](https://github.com/TheDivineLabs/DivineLabs_Installer/issues/new/choose)

This is a public direction, not a release-date commitment.

## Available

- Native AOT SDKs for Windows, macOS and Linux, x64 and ARM64.
- JSON configuration, schema completion, CLI and GitHub Action.
- Setup/update/uninstall, transactions, rollback/recovery and retained user data.
- English/Russian interface, two themes, custom cover/icon/accent.

## Next areas

- Product-specific executable icons/metadata with simple JSON integration.
- Documented signing/notarization handoff and release integrity workflow.
- More application examples and clearer preflight diagnostics.
- Additional interface languages through a maintainable localization contract.
- Evaluate self-extracting delivery and native OS formats separately from the transaction engine.

Automatic online updates, services/drivers and symlink-heavy app bundles are outside this preview contract.
Prefer reproducible developer problems and small reviewable contributions.
