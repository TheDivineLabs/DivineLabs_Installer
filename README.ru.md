# DivineLabs Installer

Открытый конструктор установщиков: **Avalonia 12 + .NET 10 Native AOT**.
Windows, macOS и Linux, x64/ARM64. MIT.

Дизайн перенесён из установщика Idle Slayer: обложка, шаги, лицензия, параметры,
прогресс и единый стиль удалятора. Есть светлая/тёмная темы и русский/английский.
Игровые изображения в репозиторий не включены.

## Подключение приложения

Скачайте SDK из артефактов успешного workflow **Build and verify**. Распакуйте;
`runtime` должен остаться рядом с `divinepack` (`divinepack.exe` на Windows).

```sh
divinepack init --dir my-installer
divinepack validate --config my-installer/installer.json
divinepack build --config my-installer/installer.json --runtime win-x64 --output my-output
```

В shell может понадобиться `./divinepack`. Другую платформу подключают через её
готовый `--runtime-dir`. Замените пример приложения своей сборкой, задайте название,
версию, издателя, точки входа, иконку, обложку и лицензию в JSON. Знать C# или
добавлять SDK в свою программу не требуется.

`dataDirectories` — каталоги пользовательских данных. Они сохраняются при обновлении
и обычном удалении; полное удаление требует отдельного выбора. Начальные файлы
приложения в эти каталоги помещать нельзя. Неучтённые файлы установщик не заменяет.

## Первая версия

0.1.0 создаёт архив с нативным установщиком и его библиотеками. Windows: ZIP с EXE,
macOS: ZIP с `.app`, Linux: TAR.GZ. Архив нужно распаковать перед запуском.
Самораспаковывающийся одиночный EXE, MSI, PKG, DEB/RPM пока не создаются.
Native AOT убирает необходимость отдельно устанавливать .NET; системные графические
зависимости ОС остаются. Исполняемый файл пока сохраняет идентичность DivineLabs;
настройки оформления из конфига применяются к интерфейсу.

Реализованы установка, обновление с откатом, журнал операции и восстановление после
аварийного завершения процесса, удаление и повторная установка с сохранением данных.
CI собирает и проверяет Native AOT на шести сочетаниях ОС/архитектуры.
Поддержка ОС считается проверенной после её успешной нативной сборки и smoke-проверки.

Нет автоматической доставки обновлений, установки служб/драйверов, подписи или
notarization. Подпись — отдельный процесс выпуска издателя. SHA-256 подтверждает
целостность, а не подлинность. Пакеты с symlink пока отклоняются, в том числе некоторые
сложные macOS `.app`. На macOS автоматические ярлыки Dock/рабочего стола не создаются.

Полные команды, схема, интеграции и ограничения — в [README.md](README.md).
